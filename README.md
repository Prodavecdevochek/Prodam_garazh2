# 🗺️ Анализатор топографических съёмок

Автоматический инструмент для анализа топографических съёмок, построения рельефа и расчёта земляных работ. Работает прямо в браузере — не нужно устанавливать программы на компьютер.

---

## 🎯 Что умеет модель

- 📂 **Загружать файлы** в форматах PDF, JPEG, PNG
- 🔍 **Распознавать высотные отметки** на карте (автоматически или вручную)
- 🏠 **Находить постройки** (дома, навесы) и исключать их из расчёта
- 🔴 **Определять границы участка** по красной линии
- 🌡️ **Строить тепловую карту рельефа** с цветовой шкалой высот
- 🚜 **Рассчитывать выравнивание** — где срезать, где насыпать грунт
- 📐 **Показывать разрез** — профиль рельефа через центр участка
- 🎨 **Создавать 3D модель** с плоскостью выравнивания
- 📊 **Считать объёмы земляных работ** в кубических метрах

---

## 🧠 Как это работает (простыми словами)

1. **Вы загружаете файл** топографической съёмки (PDF или картинку).

2. **Модель "смотрит" на изображение** и находит:
   - 🔴 Красную линию — это граница вашего участка
   - 🏠 Тёмные прямоугольники с буквами (Ж, Н, Ф) — это постройки
   - 🔢 Числа вида `26.07`, `25.93` — это отметки высот

3. **Вы помогаете модели** — указываете:
   - Масштаб карты (например, 1:500)
   - Минимальную и максимальную высоту на участке
   - Желаемую высоту после выравнивания

4. **Модель строит рельеф** — соединяет все точки высот плавной поверхностью (как натягивает ткань на колышки).

5. **Модель считает** — сколько кубометров грунта нужно срезать (где высоко) и насыпать (где низко), чтобы получить ровную площадку.

6. **Вы получаете результат** — красивые карты, графики и точные цифры для сметы.

## 🚀 Как пользоваться (пошаговая инструкция)

### Шаг 1. Откройте приложение

Вам дадут ссылку вида:
https://xxxxx.gradio.live
Откройте её в любом браузере (Chrome, Firefox, Edge).

### Шаг 2. Загрузите файл

1. Нажмите кнопку **"📄 Загрузите файл"**
2. Выберите PDF или изображение топографической съёмки
3. Дождитесь загрузки (появится имя файла)

### Шаг 3. Укажите параметры

#### 📏 Масштаб карты
- Если знаете — введите в формате `1:500`, `1:1000`, `1:2000`
- Если не знаете — **оставьте пустым**, модель определит сама

#### ⬇️ Минимальная высота
- Посмотрите на карту и найдите **самое маленькое число** (например, `24.87`)
- Введите его в это поле
- ⚠️ **Это обязательно для точного результата!**

#### ⬆️ Максимальная высота
- Найдите **самое большое число** на карте (например, `26.07`)
- Введите его сюда

#### 🎯 Целевая высота (необязательно)
- На какую высоту хотите выровнять участок?
- **Оставьте пустым или введите 0** — модель сама выберет оптимальную (среднюю)

### Шаг 4. Нажмите "🔍 Анализировать"

Подождите 10-30 секунд. Модель обработает файл и покажет результаты.

### Шаг 5. Изучите результаты

Результаты отображаются во **вкладках**:

| Вкладка | Что показывает |
|---------|---------------|
| 📊 **Статистика** | Все цифры: высоты, объёмы, площадь |
| 🖼️ **Оригинал** | Ваше исходное изображение |
| 🌡️ **Тепловая карта** | Рельеф в цветах (синий = низко, красный = высоко) |
| 🚜 **Выравнивание** | Где срезать (красный), где насыпать (синий) |
| 📐 **Разрез** | Профиль рельефа через центр участка |
| 🎨 **3D модель** | Объёмное изображение рельефа |
| 📝 **Лог** | Технические детали обработки |

### Шаг 6. Сохраните результаты

- Нажмите правой кнопкой на любую картинку → **"Сохранить изображение как..."**
- Цифры из вкладки "Статистика" можно скопировать в Excel или Word

### Шаг 7. Обработайте следующий файл

Нажмите кнопку **"🗑️ Очистить"** и загрузите новый файл. Перезапускать приложение не нужно!
